## About
**Social Media API** is real web application that users could upload posts, add comments on other user`s post, also react on other posts, and every user have a profile.

## Features
### User Authentication
- User registration and login.

- JWT-based authentication.

- Access and refresh token management.

- Secure password hashing.

- Logout and token revocation.

### User Management
- Retrieve user information.

- Role-based-access control (RABC).

- Protected adminisitrative operations.

### Posts Management
- create, retrieve, update, and delete posts.

- Authorization checks for post ownership.

### Comments Management
- create, retrieve, update, and delete comments.

- Access control based on user roles and resource ownership.

### Reactions System
- Support for multiple reaction types, including LIKE, 
LOVE, FUNNY, and SAD.

### Input Validation & Error Handling
- Request validation using Zod.

- Centralized error handling.

- Consistent HTTP status codes and error responses.

### Security
- CSRF protection for applicable requests.

- Rate limiting.

- Security headers using Helmet.

- Input sanitization and validation.

### API Documentation
- Interactive API documentation using Swagger UI and OpenAPI.

### Automated Testing
- Unit and integration tests using Jest and Supertest.

- Test coverage reporting.

- Continuous Integration (CI) using GitHub Actions.
